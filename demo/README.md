# Demo

Live demo for [`@jyothiswarup/pdf-template-builder`](https://www.npmjs.com/package/@jyothiswarup/pdf-template-builder) and [`@jyothiswarup/pdf-template-engine`](https://www.npmjs.com/package/@jyothiswarup/pdf-template-engine).
Deployed to GitHub Pages by `.github/workflows/deploy-demo.yml` on every push to `main` that touches `demo/`.

```bash
npm install
npm run dev          # local dev server
npm run build        # production build in dist/
npm run make-sample  # regenerate public/sample-certificate.pdf
```
